# Ανίχνευση και Ανάλυση Θαλάσσιων Καυσώνων στην Ανατολική Μεσόγειο με Δορυφορικά Δεδομένα SST

*Detection and Analysis of Marine Heatwaves in the Eastern Mediterranean using Satellite SST Data*

## Περιγραφή

Αυτό το project ανιχνεύει και αναλύει επεισόδια θαλάσσιου καύσωνα (Marine Heatwaves, MHW) σε δύο
γεωγραφικές κλίμακες: (α) σε σημείο-αναφορά στον Πατραϊκό Κόλπο (περιοχή Πάτρας), και (β) σε ευρύτερη
χωρική περιοχή στο Ιόνιο Πέλαγος, ανοιχτά Κυλλήνης-Κεφαλονιάς-Αράξου
(δυτικά της εισόδου του Πατραϊκού Κόλπου). Χρησιμοποιούνται δορυφορικά δεδομένα θερμοκρασίας
επιφάνειας θάλασσας (Sea Surface Temperature - SST) από την υπηρεσία Copernicus Marine Service.

Η ανάλυση εφαρμόζει την καθιερωμένη επιστημονική μεθοδολογία των Hobday et al. (2016, 2018) για τον
ορισμό και τον εντοπισμό θαλάσσιων καυσώνων, και εξετάζει τόσο χρονικές τάσεις (2014-2026) όσο και
χωρικά μοτίβα έντασης/συχνότητας στην ευρύτερη περιοχή.

## Στόχοι

- Ανίχνευση επεισοδίων θαλάσσιου καύσωνα σε σημείο-αναφορά (Πατραϊκός Κόλπος, περιοχή Πάτρας)
- Ανάλυση τάσεων συχνότητας/έντασης καυσώνων 2014-2026
- Χωρική ανάλυση στο Ιόνιο (ανοιχτά Κυλλήνης-Κεφαλονιάς-Αράξου): εντοπισμός περιοχών με υψηλότερη ένταση/συχνότητα καυσώνων
- Σύγκριση πρόσφατων ετών (2024-2026) με ιστορικό baseline

## Δεδομένα

- **Πηγή**: [Copernicus Marine Service](https://data.marine.copernicus.eu)
- **Dataset**: `SST_MED_SST_L4_REP_OBSERVATIONS_010_021` — Mediterranean Sea High Resolution L4 SST Reprocessed
- **Ανάλυση**: 0.05° χωρική ανάλυση, ημερήσια δεδομένα
- **Περίοδος**: Ιανουάριος 2014 – Ιούλιος 2026
- **Μεταβλητή**: `analysed_sst` (θερμοκρασία επιφάνειας θάλασσας, Kelvin → μετατράπηκε σε Celsius)

## Μεθοδολογία

Η ανίχνευση θαλάσσιων καυσώνων ακολουθεί τη μέθοδο **Hobday et al. (2016, 2018)**:

1. Υπολογισμός climatology baseline (μέση θερμοκρασία ανά ημέρα του έτους, πολυετής μέσος όρος)
2. Υπολογισμός κατωφλίου καύσωνα (90ό εκατοστημόριο)
3. Εντοπισμός περιόδων όπου η παρατηρούμενη θερμοκρασία υπερβαίνει το κατώφλι για **τουλάχιστον 5
   συνεχόμενες ημέρες**
4. Κατηγοριοποίηση σοβαρότητας (moderate / strong / severe / extreme)

Υλοποιήθηκε με τη βιβλιοθήκη [`xmhw`](https://github.com/coecms/xmhw) (xarray-based έκδοση του
αρχικού αλγορίθμου του Eric Oliver).

## Εγκατάσταση & Εκτέλεση

### 1. Κλωνοποίηση repository
```bash
git clone <url-του-repository>
cd <όνομα-φακέλου>
```

### 2. Εγκατάσταση βιβλιοθηκών
```bash
pip install -r requirements.txt
```

### 3. Λογαριασμός Copernicus Marine Service
Χρειάζεται δωρεάν λογαριασμός στο [data.marine.copernicus.eu](https://data.marine.copernicus.eu).
Μετά την εγκατάσταση του `copernicusmarine`, κάνε login:
```bash
copernicusmarine login
```

### 4. Εκτέλεση
Άνοιξε το `ocean_analysis.ipynb` σε Jupyter/JupyterLab και τρέξε τα κελιά με τη σειρά (η λήψη
δεδομένων γίνεται αυτόματα από τα πρώτα κελιά του notebook).

## Βασικά Ευρήματα

- Εντοπίστηκαν πολλαπλά επεισόδια θαλάσσιου καύσωνα στην περιοχή μελέτης κατά την περίοδο 2014-2026
- Το **2024** ξεχώρισε ως έτος-ρεκόρ, με το πιο έντονο επεισόδιο (21 ημέρες, Μάρτιος-Απρίλιος 2024) και
  το μεγαλύτερης διάρκειας επεισόδιο (46 ημέρες, Αύγουστος-Σεπτέμβριος 2024) της περιόδου μελέτης
- Χωρική ανάλυση στο Ιόνιο (Κυλλήνη-Κεφαλονιά-Άραξος) έδειξε αυξημένη ένταση καύσωνα προς τα ανατολικά
  του πλέγματος, κοντά στην είσοδο του Πατραϊκού, πιθανόν λόγω περιορισμένης υδάτινης ανταλλαγής στα
  πιο κλειστά νερά
- Τα ευρήματα ευθυγραμμίζονται με τη διεθνή βιβλιογραφία που χαρακτηρίζει τη Μεσόγειο ως κλιματικό
  hotspot με αυξανόμενη συχνότητα/ένταση θαλάσσιων καυσώνων

## Περιορισμοί

- Το bounding box της χωρικής ανάλυσης περιλαμβάνει τμήματα ξηράς (ακτογραμμή), τα οποία εμφανίζονται
  ως περιοχές χωρίς έγκυρα δεδομένα (NaN) — επιβεβαιώθηκε μέσω ελέγχου ποιότητας δεδομένων
- Climatology baseline βασίζεται σε ~12 χρόνια δεδομένων· ο επίσημος ορισμός Hobday προτείνει
  τουλάχιστον 30ετία για πλήρως αντιπροσωπευτικό baseline
